# ReAct: Synergizing Reasoning and Acting in Language Models

**发表会议/期刊（如果有）**: ICLR 2023

## 1. 文献核心 Insight / Contribution
本文提出 ReAct，一种通过交错生成推理轨迹（thought）与任务动作（action）来协同语言模型推理与行动能力的新型范式。其核心洞察是：将语言作为内部推理空间，允许模型动态维护工作记忆、分解目标、处理异常并利用外部知识，从而在知识密集型推理任务（如 HotpotQA、Fever）和交互式决策任务（如 ALFWorld、WebShop）中同时提升性能与可解释性。该方法通过少量上下文示例进行提示（few-shot prompting），无需额外训练，显著优于单纯推理或单纯行动的方法，并展示了微调进一步提升性能的潜力。

## 2. 与本工作的关系
ReAct 构建了长时序语言代理的基本架构，其中代理通过“思考-行动-观察”的循环与环境交互，交互过程天然包含异步、稀疏的反馈信号（如环境观察、最终任务完成信号）。然而，ReAct 本身完全依赖于预训练的静态语言模型和提示模板，并未涉及策略学习中的信用分配（credit assignment）问题——当反馈延迟到来时，无法有效将奖励归因到历史关键步骤。

本工作（ECR-GRPO）正是面向这类长时序代理的异步反馈场景，将“思考-行动”轨迹作为事件流，通过证据条件化的信用填充（event-conditioned credit refill）为历史步骤分配回报，并与 GRPO 式群组相对优势结合进行策略更新。ReAct 为 ECR-GRPO 提供了天然的应用环境（如 ALFWorld、WebShop），但其无学习的提示范式也暴露出对强化学习信用分配的迫切需求：在面临工具延迟、部分奖励或非本地评估时，仅靠提示无法自适应优化，这正是 ECR-GRPO 所要解决的问题。

## 3. 讨论
ReAct 的强项在于利用大型语言模型的先验知识和推理能力，以极低成本（仅需数个示例）实现了复杂的交互式任务解决，并带来高度的可解释性和人工可干预性。但其局限性同样明显：

1. **缺乏策略学习机制**：ReAct 通过固定的提示决定行为，无法根据交互经验自适应改进。在更长的任务或更嘈杂的反馈下，无法动态调整信用分配，可能导致次优行为。
2. **异步反馈未建模**：虽然 ReAct 轨迹中包含多步观测和最终成功信号，但该方法没有区分即时反馈、延迟反馈、缺失反馈等不同事件，也未对历史步骤进行差别化奖励归因。这直接限制了其通过强化学习进一步提升的可能。
3. **提示工程依赖**：性能高度依赖精心设计的示例和思维模式，对于大规模动作空间或高度变化的环境，可扩展性受限。

这些局限恰好为 ECR-GRPO 提供了发端动机：在 ReAct 风格的代理框架上，引入事件化信用分配和证据条件化的步骤回报，能够将 RL 学习引入到无提示微调的场景中，并系统性地解决异步、部分、非本地反馈带来的信用分配难题。

## 4. 总结
ReAct 证明了在语言模型中融合推理与行动能够极大提升长时序决策任务的解决能力与可解释性，为语言代理研究树立了重要基准。其框架天然适用于我们提出的 ECR-GRPO 异步信用分配方法，但 ReAct 的纯提示范式无法处理异步反馈的奖励归因，这一缺口直接引导了我们将事件化信用填充与 GRPO 式策略优化相结合的研究方向。
