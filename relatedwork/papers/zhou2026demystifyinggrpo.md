# Demystifying Group Relative Policy Optimization: Its Policy Gradient is a U-Statistic

**发表会议/期刊（如果有）**: arXiv (2026)

## 1. 文献核心 Insight / Contribution
本文从统计学角度解构了 GRPO 的核心机理，首次证明了 GRPO 的策略梯度本质上是一个二阶 U-统计量。利用 Hoeffding 分解，将 GRPO 梯度拆分为期望梯度、与 oracle（有真实价值函数）梯度等价的一阶项、以及高阶残余项。基于此，文章给出了梯度估计量的有限样本均方误差（MSE）上界以及渐近分布，揭示了 GRPO 的 **oracle 性质**（组大小足够大时，近似等价于使用真实 critic 的算法）与 **最优性**（在一大类 policy gradient 方法中渐近最小化 MSE 和次优间隙）。进一步，推导出一条普适的 **scaling law**，指出在总采样预算固定时，最优组大小 G* 仅取决于数据与模型，而与迭代次数、预算规模等无关，并在 GSM8K 和 MATH 任务上验证了其普适性。

## 2. 与本工作的关系
本工作专注于**异步、延迟、部分、弱证据、非局部**反馈下的长链 LLM Agent 的信用分配，提出 ECR‑GRPO 将奖励建模为可指派事件，并通过证据条件核对历史步进行信用回填。而本文聚焦于标准 GRPO（同步即时终端奖励、组内独立采样）的理论基础，不涉及事件流、缺失奖励、延迟或非局部关系。两者的联系在于：ECR‑GRPO 最终仍将回填后的步级回报送入 GRPO 风格的组相对优势更新，因此本文所揭示的 GRPO 梯度 U-统计量结构及其 MSE 性质，理论上可扩展至事件化信用分配后的估计量分析；但当前本文的设定并未覆盖我们故事线中的核心挑战（异步、部分、弱证据），其 oracle 性质假设所有奖励在步结束时即可获得，而我们的场景下反馈到达时间和归属均不确定。

## 3. 讨论
**优势**：提供了严谨的统计理论，解释了为何 GRPO 使用组平均作为 baseline 是有效的，并给出有限样本和渐近的性能保证；scaling law 为实际训练中的组大小选择提供了原则性指导。  
**局限**：假设奖励在每组采样后立即完整获得，且只考虑二元正确性奖励；未涉及长链交互中奖励的延迟、缺失、中断或非局部关联。这导致其理论无法直接应用于我们的异步 Agent 场景：ECR‑GRPO 需要处理奖励缺失（“dropped” 事件）、非局部事件对应更早步骤、以及证据核带来的非平稳依赖。本文虽然证明 GRPO 梯度具有 oracle 性质，但若将其用于事件化重填后的步骤奖励，其 U-统计量结构将变为对事件-步骤对的条件核平均，方差特性可能发生改变，需进一步分析。此外，本文理论未涵盖 reward normalization、importance sampling 和 KL 约束的完整生产实现，虽然附录有所扩展，但仍与我们的 gated evidence 路由对应不上。  
**对我们方法的激励**：本文的 U-统计量分析框架提示我们：将 ECR‑GRPO 的 event-to-step 信用重填与组相对优势结合后，其梯度可能仍有类似的低阶/高阶分解，可借以评估不同证据源和回填延迟引入的额外方差，为设计 gated evidence 机制提供理论支持。

## 4. 总结
本文通过将 GRPO 梯度建立为 U-统计量，系统性地解释了该算法的统计有效性与最优性，并给出了普适的最优组大小原理。尽管未涉足异步反馈下的信用分配，但其建立的 U-统计量视角为 ECR‑GRPO 在事件化奖励场景下的方差分析提供了理论基础，有助于后续论证我们的证据条件回填在 Gradent‑Advantage 层面的理论保真度。
